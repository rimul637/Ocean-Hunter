# Ocean Hunter

An offline Android underwater action adventure. The campaign spans 60 missions and six boss encounters. Endless mode rotates through underwater environments and continues until the submarine is destroyed.

## Controls

| Action | Touch or mouse | Keyboard |
| --- | --- | --- |
| Move | Drag the joystick | WASD or arrows |
| Fire torpedoes | Hold FIRE | Space |
| Shield | Select SHIELD | E |
| Pause or go back | Select pause or BACK | Escape |
| Navigate and select menus | Select a button | Tab or arrows, then Enter |

Use touch with two fingers to steer and fire simultaneously. Mouse users can pair the on-screen controls with keyboard movement or firing.

## Build

Use JDK 17 or 21, Android SDK Platform 36 and SDK Build Tools 36.0.0. Open this folder in Android Studio or use the Gradle wrapper.

```sh
./gradlew :app:testReleaseUnitTest :app:lintRelease :app:assembleRelease :app:bundleRelease
python3 tools/verify_manifest.py "$(find app/build/intermediates/merged_manifests -path '*release*AndroidManifest.xml' -print -quit)"
```

Set `OCEAN_SIGNING_STORE`, `OCEAN_STORE_PASSWORD`, `OCEAN_KEY_ALIAS`, and `OCEAN_KEY_PASSWORD` for a signed local build. The alias for the dedicated release key is `ocean-hunter-release`. Keep the keystore and passwords private.

GitHub Actions builds the app on main and on pull requests. The `v1.0.0` tag runs the signed release job when repository secrets `OCEAN_KEYSTORE_BASE64` and `OCEAN_STORE_PASSWORD` are configured. The first contains a single-line Base64 encoding of the private PKCS#12 keystore. The second is its password.

## Platform and assets

Package `com.oceanhunter.hunter`, version name `1.0.0`, version code `1`. Compile and target API 36, minimum API 26. Landscape is preferred on compact screens. Gameplay scales without stretching when Android or the window manager restricts orientation. No network, billing, analytics, haptics or runtime permissions are used. DataStore keeps scores, coins, upgrades and settings on the device.

The supplied Ocean Hunter image is packaged byte-for-byte as the launcher icon. In-game scenery and sprites are original Canvas art, with offline sound and music generated by `tools/synthesize_audio.py` using Python and FFmpeg.

The automated checks verify package configuration and game logic without an emulator. Visual accuracy, real-device frame rates and device availability in Google Play Console require separate verification.
